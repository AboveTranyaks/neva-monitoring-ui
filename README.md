# Нева Мониторинг

Интерактивный прототип рабочего места оператора охранного мониторинга.

## Возможности

- фильтрация и поиск тревог;
- выбор объекта и обновление карточки;
- принятие и перехват тревоги;
- отправка ГБР и журнал событий;
- список операторов онлайн;
- выдвижное меню;
- кликабельные телефонные и картографические действия.

Статическая сборка находится в каталоге `dist` и публикуется через GitHub Pages.
